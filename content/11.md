## 1. 未标记样本 (Unlabeled Samples)

### 1.1 背景与动机
- **现实需求**：在很多现实任务中，有标记样本（Labeled Samples）极难获取且收集成本高昂，而未标记样本（Unlabeled Samples）极易且廉价获取。如何自动利用海量未标记样本来提升学习性能，是半监督学习的核心诉求。
- **直观理解 (图 13.1)**：
  - 仅利用一正一反两个有标记样本时，划分面只能设在两点中垂线上。
  - 引入未标记样本后，其展现出来的整体数据分布（如簇状分布）可帮助重新勾画清晰的分类决策边界。
- **三种学习模式的对比 (纯半监督 vs 主动学习 vs 直推学习)**：
  - **主动学习 (Active Learning)**：通过与外界交互（如品瓜师、标注者），主动挑选价值最高的未标记样本进行人工查询标注，是一种“有人参与”的模式。
  - **(纯) 半监督学习 (Pure Semi-Supervised Learning)**：自动利用未标记样本，不需要外部交互。假定未标记样本并非待预测样本，目标是获得对未知新样本（开放世界假设，Open World）的最优泛化性能。
  - **直推学习 (Transductive Learning)**：同样自动利用未标记样本，但假定这些未标记样本恰好就是待测试/预测的样本（封闭世界假设，Closed World），目标是在这些特定的未标记样本上取得最优结果。

### 1.2 未标记样本引入的核心假设
要想利用未标记样本，必须做一些连接“数据分布信息”与“类别标记”的假设：
- **聚类假设 (Cluster Assumption)**：假设数据存在簇结构，同一个簇的样本属于同一个类别。
- **流形假设 (Manifold Assumption)**：假设数据分布在一个流形结构上，邻近的样本拥有相似的输出值。可看作聚类假设的推广，由于对输出值没有离散类别限制，适用范围更广。
- **本质归结**：“相似的样本拥有相似的输出”。

## 2. 生成式方法 (Generative Methods)

### 2.1 基本假设与高斯混合模型 (GMM) 设定
- **基本假设**：所有数据（无论是否有标记）都是由同一个潜在的模型生成的。未标记样本的标记可看作模型的缺失参数。
- **混合概率密度**：
  $$p(\mathbf{x}) = \sum_{i=1}^N \alpha_i \cdot p(\mathbf{x} \mid \boldsymbol{\mu}_i, \mathbf{\Sigma}_i)$$
  其中 $\alpha_i \ge 0$ 且 $\sum_{i=1}^N \alpha_i = 1$ 为混合系数，$p(\mathbf{x} \mid \boldsymbol{\mu}_i, \mathbf{\Sigma}_i)$ 是第 $i$ 个高斯混合成分的概率密度。
- **基于最大化后验概率的预测规则 (式 13.2)**：
  $$f(\mathbf{x}) = \arg\max_{j \in \mathcal{Y}} p(y = j \mid \mathbf{x}) = \arg\max_{j \in \mathcal{Y}} \sum_{i=1}^N p(y = j \mid \Theta = i, \mathbf{x}) \cdot p(\Theta = i \mid \mathbf{x})$$
  - 假定第 $i$ 个类别对应于第 $i$ 个高斯混合成分，即 $p(y = j \mid \Theta = i, \mathbf{x}) = 1$ (当 $i=j$ 时)，否则为 $0$。
  - 项 $p(y = j \mid \Theta = i, \mathbf{x})$ 仅能使用有标记数据进行估计。
  - 项 $p(\Theta = i \mid \mathbf{x})$ （即样本由第 $i$ 个成分生成的后验概率）不涉及标记，可同时利用有标记和未标记数据，在无标记数据规模大时，该项估计将极大地更准确。
  - 样本由第 $i$ 个成分生成的后验概率计算公式：
    $$p(\Theta = i \mid \mathbf{x}) = \frac{\alpha_i \cdot p(\mathbf{x} \mid \boldsymbol{\mu}_i, \mathbf{\Sigma}_i)}{\sum_{k=1}^N \alpha_k \cdot p(\mathbf{x} \mid \boldsymbol{\mu}_k, \mathbf{\Sigma}_k)}$$

### 2.2 联合对数似然 (式 13.4)
给定有标记样本集 $D_l = \{(\mathbf{x}_1, y_1), \dots, (\mathbf{x}_l, y_l)\}$ 和未标记样本集 $D_u = \{\mathbf{x}_{l+1}, \dots, \mathbf{x}_{l+u}\}$，独立同分布下参数 $\{(\alpha_i, \boldsymbol{\mu}_i, \mathbf{\Sigma}_i) \mid 1 \le i \le N\}$ 的对数似然函数为：
$$LL(D_l \cup D_u) = \sum_{(\mathbf{x}_j, y_j) \in D_l} \ln \left( \sum_{i=1}^N \alpha_i \cdot p(\mathbf{x}_j \mid \boldsymbol{\mu}_i, \mathbf{\Sigma}_i) \cdot p(y_j \mid \Theta = i, \mathbf{x}_j) \right) + \sum_{\mathbf{x}_j \in D_u} \ln \left( \sum_{i=1}^N \alpha_i \cdot p(\mathbf{x}_j \mid \boldsymbol{\mu}_i, \mathbf{\Sigma}_i) \right)$$
包含**有监督项**与**无监督项**。

### 2.3 EM 算法求解步骤
- **E 步 (Expectation)**：根据当前模型参数计算未标记样本 $\mathbf{x}_j \in D_u$ 属于各高斯混合成分的后验概率：
  $$\gamma_{ji} = \frac{\alpha_i \cdot p(\mathbf{x}_j \mid \boldsymbol{\mu}_i, \mathbf{\Sigma}_i)}{\sum_{k=1}^N \alpha_k \cdot p(\mathbf{x}_j \mid \boldsymbol{\mu}_k, \mathbf{\Sigma}_k)}$$
- **M 步 (Maximization)**：基于后验概率 $\gamma_{ji}$ 更新模型参数。令 $l_i$ 表示第 $i$ 类的有标记样本数目（即 $l_i = \sum_{(\mathbf{x}_j, y_j) \in D_l} \mathbb{I}(y_j = i)$）：
  $$\boldsymbol{\mu}_i = \frac{1}{\sum_{\mathbf{x}_j \in D_u} \gamma_{ji} + l_i} \left( \sum_{\mathbf{x}_j \in D_u} \gamma_{ji} \mathbf{x}_j + \sum_{(\mathbf{x}_j, y_j) \in D_l \land y_j = i} \mathbf{x}_j \right)$$
  $$\mathbf{\Sigma}_i = \frac{1}{\sum_{\mathbf{x}_j \in D_u} \gamma_{ji} + l_i} \left( \sum_{\mathbf{x}_j \in D_u} \gamma_{ji} (\mathbf{x}_j - \boldsymbol{\mu}_i)(\mathbf{x}_j - \boldsymbol{\mu}_i)^{\mathrm{T}} + \sum_{(\mathbf{x}_j, y_j) \in D_l \land y_j = i} (\mathbf{x}_j - \boldsymbol{\mu}_i)(\mathbf{x}_j - \boldsymbol{\mu}_i)^{\mathrm{T}} \right)$$
  $$\alpha_i = \frac{1}{m} \left( \sum_{\mathbf{x}_j \in D_u} \gamma_{ji} + l_i \right)$$
  其中 $m = |D_l| + |D_u| = l + u$。

### 2.4 生成式方法的特点
- **模型推广**：可将高斯混合模型换为混合专家模型、朴素贝叶斯模型等。
- **优缺点**：
  - 优点：算法简单易实现，在标记样本极少时由于先验结构强，往往表现优异。
  - 致命缺点：**极度依赖模型假设的准确性**。若设定的生成模型与真实数据分布不吻合，引入无标记数据反而会损害泛化性能。而在实际应用中，准确预测模型分布难度极大。

## 3. 半监督支持向量机 (Semi-Supervised SVM)

### 3.1 TSVM 概念与直观区别
- **核心概念 (TSVM - Transductive Support Vector Machine)**：针对二分类问题的半监督学习方法。它尝试对未标记样本进行所有可能的标记指派，从中寻找一个在所有样本（有标记样本 + 指派了伪标记的未标记样本）上**间隔最大化**的划分超平面。
- **SVM 划分 vs S3VM 划分 (图)**：
  - 标准 SVM 仅利用有标记样本，容易切过未标记样本密集的高密度区域（低间隔）。
  - S3VM (如 TSVM) 会顺应未标记样本分布，寻找一条穿过稀疏区域（低密度通道）的超平面（高间隔）。

### 3.2 TSVM 形式化优化目标 (式 13.9)
给定 $D_l = \{(\mathbf{x}_1, y_1), \dots, (\mathbf{x}_l, y_l)\}$ 和 $D_u = \{\mathbf{x}_{l+1}, \dots, \mathbf{x}_{l+u}\}$，其中 $y_i \in \{-1, +1\}$，$l \ll u$。TSVM 目标为给 $D_u$ 确定标记指派 $\hat{\mathbf{y}} = (\hat{y}_{l+1}, \dots, \hat{y}_{l+u})$（$\hat{y}_i \in \{-1, +1\}$），使得：
$$\min_{\mathbf{w}, b, \hat{\mathbf{y}}, \boldsymbol{\xi}} \frac{1}{2} \|\mathbf{w}\|_2^2 + C_l \sum_{i=1}^l \xi_i + C_u \sum_{i=l+1}^{l+u} \xi_i$$
$$\text{s.t.} \quad y_i (\mathbf{w}^{\mathrm{T}}\mathbf{x}_i + b) \ge 1 - \xi_i, \quad i = 1, 2, \dots, l$$
$$\hat{y}_j (\mathbf{w}^{\mathrm{T}}\mathbf{x}_j + b) \ge 1 - \xi_j, \quad j = l+1, l+2, \dots, l+u$$
$$\xi_i \ge 0, \quad i = 1, 2, \dots, l+u$$
- 其中 $C_l$ 和 $C_u$ 是平衡模型复杂度、有标记与未标记样本重要程度的折中参数。
- 求解难点：穷举所有可能标记指派属于指数爆炸问题，实际需要局部搜索等高效近似优化策略。

### 3.3 类别不平衡问题与拆分 $C_u$ 改进
- **问题**：在对未标记样本指派及调整的过程中，极易偏向某一类别造成严重失衡。
- **解决方法**：将无标记惩罚项 $C_u$ 拆分为 $C_u^+$（对应伪标记为正的样本）和 $C_u^-$（对应伪标记为负的样本）两项。
- **初始化约束**：在初始化时令：
  $$C_u^+ = \frac{u_-}{u_+} C_u^-$$
  其中 $u_+$ 与 $u_-$ 分别为伪标记指派为正、反例的未标记样本数。

### 3.4 TSVM 局部搜索算法流程
```
输入：有标记样本集 D_l；未标记样本集 D_u；折中参数 C_l, C_u。
过程：
1: 用 D_l 训练一个标准 SVM_l；
2: 用 SVM_l 对 D_u 中的样本进行预测，得到初始伪标记 y_hat = (y_hat_{l+1}, ..., y_hat_{l+u})；
3: 初始化 C_u 为极小值 (C_u << C_l)；
4: while C_u < C_l do
5:   基于 D_l, D_u, y_hat, C_l, C_u 求解式(13.9)，得到 (w, b), \xi；
6:   while 存在一对未标记样本 x_i 与 x_j 满足：
           (y_hat_i * y_hat_j < 0) 且 (xi_i > 0) 且 (xi_j > 0) 且 (xi_i + xi_j > 2) do
7:     y_hat_i = -y_hat_i；
8:     y_hat_j = -y_hat_j；
9:     基于 D_l, D_u, y_hat, C_l, C_u 重新求解式(13.9)，更新 (w, b), \xi；
10:  end while
11:  C_u = min{2 * C_u, C_l}；
12: end while
输出：未标记样本的预测结果 y_hat = (y_hat_{l+1}, ..., y_hat_{l+u})
```
- **核心置换条件分析 (第 6-10 行)**：若有两样本异号且松弛变量和大于 $2$，说明分类面发生了严重错误，交换其标记后重新求解，可保证式 (13.9) 的目标函数值**单调下降**。

## 4. 图半监督学习 (Graph-Based Semi-Supervised Learning)

### 4.1 基本思想与图映射关系
- **图映射**：每个样本映射为图的结点，若两样本相似度高，则对应的结点间有强连接边。
- **色彩传播直观解释**：有标记样本节点是“已染色”的，未标记样本节点是“未染色”的，半监督学习过程即颜色在图上顺着边扩散传播的过程。
- **数学优势**：可以用图关联的矩阵运算推导与分析算法性质。

### 4.2 亲和矩阵构建 (Affinity Matrix)
给定样本集，基于高斯函数构建图 $G=(V, E)$ 的边强度矩阵 $\mathbf{W}$：
$$(\mathbf{W})_{ij} = 
\begin{cases} 
\exp\left( - \frac{\|\mathbf{x}_i - \mathbf{x}_j\|_2^2}{2\sigma^2} \right), & \text{if } i \ne j \\
0, & \text{otherwise} 
\end{cases}$$
其中 $\sigma$ 为高斯函数带宽参数。度矩阵 $\mathbf{D} = \text{diag}(d_1, \dots, d_{l+u})$，其对角线元素为 $d_i = \sum_{j=1}^{l+u} (\mathbf{W})_{ij}$。

### 4.3 能量函数最小化 (式 13.12 & 式 13.15)
- **能量函数**：
  $$E(f) = \frac{1}{2} \sum_{i=1}^{l+u} \sum_{j=1}^{l+u} (\mathbf{W})_{ij} (f(\mathbf{x}_i) - f(\mathbf{x}_j))^2 = \mathbf{f}^{\mathrm{T}} (\mathbf{D} - \mathbf{W}) \mathbf{f} = \mathbf{f}^{\mathrm{T}} \mathbf{L} \mathbf{f}$$
  其中 $\mathbf{L} = \mathbf{D} - \mathbf{W}$ 为拉普拉斯矩阵。将函数 $\mathbf{f}$ 划分为有标记部分 $\mathbf{f}_l$ 和未标记部分 $\mathbf{f}_u$。
- **分块矩阵表示**：
  $$\mathbf{W} = \begin{bmatrix} \mathbf{W}_{ll} & \mathbf{W}_{lu} \\ \mathbf{W}_{ul} & \mathbf{W}_{uu} \end{bmatrix}, \quad \mathbf{D} = \begin{bmatrix} \mathbf{D}_{ll} & \mathbf{0}_{lu} \\ \mathbf{0}_{ul} & \mathbf{D}_{uu} \end{bmatrix}$$
  能量函数可以重写为：
  $$E(f) = (\mathbf{f}_l^{\mathrm{T}} \ \mathbf{f}_u^{\mathrm{T}}) \left( \begin{bmatrix} \mathbf{D}_{ll} & \mathbf{0}_{lu} \\ \mathbf{0}_{ul} & \mathbf{D}_{uu} \end{bmatrix} - \begin{bmatrix} \mathbf{W}_{ll} & \mathbf{W}_{lu} \\ \mathbf{W}_{ul} & \mathbf{W}_{uu} \end{bmatrix} \right) \begin{bmatrix} \mathbf{f}_l \\ \mathbf{f}_u \end{bmatrix}$$
  对 $\mathbf{f}_u$ 求偏导并令其为 $0$：
  $$\frac{\partial E(f)}{\partial \mathbf{f}_u} = 0 \implies \mathbf{f}_u = (\mathbf{D}_{uu} - \mathbf{W}_{uu})^{-1} \mathbf{W}_{ul} \mathbf{f}_l$$
  引入标记传播矩阵 $\mathbf{P} = \mathbf{D}^{-1}\mathbf{W}$，上式可等价重写为：
  $$\mathbf{f}_u = (\mathbf{I} - \mathbf{P}_{uu})^{-1} \mathbf{P}_{ul} \mathbf{f}_l$$
  此为针对二分类问题的标记传播闭式解。

### 4.4 多分类标记传播与规范拉普拉斯矩阵
- **非负标记矩阵 $\mathbf{F} \in \mathbb{R}^{(l+u) \times |\mathcal{Y}|}$**：第 $i$ 行元素表示示例 $\mathbf{x}_i$ 的类别归属向量。
- **初始化**：$\mathbf{F}(0) = \mathbf{Y}$。
  $$\mathbf{Y}_{ij} = \begin{cases} 1, & \text{if } (1 \le i \le l) \land (y_i = j) \\ 0, & \text{otherwise} \end{cases}$$
- **规范拉普拉斯迭代式 (式 13.19)**：
  $$\mathbf{F}(t+1) = \alpha \mathbf{S} \mathbf{F}(t) + (1-\alpha) \mathbf{Y}$$
  其中 $\mathbf{S} = \mathbf{D}^{-1/2} \mathbf{W} \mathbf{D}^{-1/2}$ 为规范拉普拉斯矩阵，$\alpha \in (0, 1)$ 用作权衡折中参数。
- **迭代收敛的闭式解**：
  $$\mathbf{F}^* = \lim_{t\to\infty} \mathbf{F}(t) = (1-\alpha)(\mathbf{I} - \alpha \mathbf{S})^{-1} \mathbf{Y}$$
- **正则化框架等价性**：该迭代收敛解等价于下述正则化框架的全局最优解：
  $$\min_{\mathbf{F}} \frac{1}{2} \left( \sum_{i,j=1}^{l+u} (\mathbf{W})_{ij} \left\| \frac{1}{\sqrt{d_i}} \mathbf{F}_i - \frac{1}{\sqrt{d_j}} \mathbf{F}_j \right\|_2^2 + \mu \sum_{i=1}^l \|\mathbf{F}_i - \mathbf{Y}_i\|_2^2 \right)$$
  其中 $\mu = \frac{1-\alpha}{\alpha} > 0$ 为正则化参数。

### 4.5 图半监督学习的局限性
- **存储开销过大**：若样本量为 $m$，涉及图相似度矩阵大小为 $O(m^2)$，难以直接应用于大规模数据集。
- **外部样本预测困难 (Out-of-Sample Issue)**：新测试样本加入时，因为构图时没考虑它，无法轻易定位。必须重新构图运行算法，或者额外训练一个泛化分类器来做预测。

## 5. 基于分歧的方法 (Disagreement-Based Methods)

### 5.1 协同训练与多视图数据
- **基本假设**：使用多个学习器，通过彼此之间的“分歧”去共同利用未标记数据。
- **多视图 (Multi-View) 数据**：一个数据对象在不同角度拥有多组属性集。例如一部电影：
  - 视图 1：图像画面特征。
  - 视图 2：声音特征。
  - 视图 3：字幕特征。
  样本表示为 $(\langle \mathbf{x}^1, \mathbf{x}^2 \rangle, y)$，各视图的描述能力是不同的。

### 5.2 协同训练算法流程 (Co-Training)
- **输入**：有标记视图数据集 $D_l$、无标记视图数据集 $D_u$、缓冲池大小 $s$、每轮挑的正例/反例数 $p, n$、基算法 $\mathcal{L}$、迭代轮数 $T$。
- **流程**：
  1. 从 $D_u$ 随机抽取 $s$ 个样本组成缓冲池 $D_s$。
  2. 迭代过程：
     - 在各自视图的训练集 $D_l^1, D_l^2$ 上利用基算法训练分类器 $h_1, h_2$。
     - $h_1$ 对 $D_s$ 的未标记样本估计，挑出 $p$ 个高置信度正例和 $n$ 个高置信度反例，标记好伪标签，加入 $h_2$ 的训练集。
     - $h_2$ 对 $D_s$ 进行相同操作，挑出高置信度样本加入 $h_1$ 的训练集。
     - 更新缓冲池，从 $D_u$ 补充样本使其维持 $s$ 大小。
     - 如果 $h_1, h_2$ 在这一轮均无更新，则提早 Break 退出。
- **理论保证**：如果两个视图**充分（Sufficient，能支持学习器收敛）**且在给定类别标记下**条件独立（Conditionally Independent）**，则理论上能将弱学习器的性能提升到任意高。
- **实际情况**：独立性很难完美满足，但弱独立在实际中依然能显著提升性能。

### 5.3 单视图协同训练与分歧特征
- **单视图变体**：为了在没有多视图的数据上使用基于分歧的方法，可以采用不同的基算法、不同的数据子集采样（如 Bagging）、或者差异化的参数设置来制造有显著分歧（Disagreement）的不同基学习器。
- **基于分歧方法的普适优点**：
  - 较少受限于强模型分布假设。
  - 学习器简单，受损失函数非凸性、数据规模限制小。
  - 理论基础坚实，适用范围广。
- **难点**：当有标记数据极少时，如何无视图辅助下生成既有高分歧又各自保留底线精度的多个基学习器极富挑战。

## 6. 半监督聚类 (Semi-Supervised Clustering)

### 6.1 监督信息的两类形式
聚类属于无监督学习，但有时可以获取少量约束或标签等监督信息：
- **第一类：约束信息**：
  - **必连约束 (Must-link)**：两样本必须分在同一个簇中（集合 $\mathcal{M}$）。
  - **勿连约束 (Cannot-link)**：两样本不能分在同一个簇中（集合 $\mathcal{C}$）。
- **第二类：标签信息**：少量的有标记样本（集合 $S$）。

### 6.2 约束 $k$ 均值算法 (Constrained k-means)
- **核心理念**：在常规 $k$-means 算法指派样本点划分时，强制约束不能违背 $\mathcal{M}$ 和 $\mathcal{C}$ 中的关系，否则退而求其次选择距离次近且符合约束的簇；若均无法满足则报错。
- **算法伪代码**：
  ```
  输入：样本集 D；必连约束集合 M；勿连约束集合 C；聚类簇数 k。
  过程：
  1: 从 D 中随机选取 k 个样本作为初始均值向量 {mu_1, ..., mu_k}；
  2: repeat
  3:   初始化各个簇的分配为空：C_j = 空集 (1 <= j <= k)；
  4:   for i = 1, 2, ..., m do
  5:     计算样本 x_i 到各个均值向量 mu_j 的欧式距离 d_ij = ||x_i - mu_j||_2；
  6:     初始化候选簇集合 K = {1, 2, ..., k}；
  7:     is_merged = false；
  8:     while not is_merged do
  9:       从候选集合 K 中选出距离最近的簇 r = argmin_{j in K} d_ij；
  10:      检测如果把 x_i 分配到 C_r 是否会违背必连约束 M 或勿连约束 C；
  11:      if 没有违背约束 (not is_violated) then
  12:        C_r = C_r U {x_i}；
  13:        is_merged = true；
  14:      else
  15:        K = K \ {r}；
  16:        if K 为空集 then
  17:          算法中止，抛出错误提示；
  18:        end if
  19:      end if
  20:    end while
  21:  end for
  22:  for j = 1, 2, ..., k do
  23:    更新均值向量 mu_j = (1 / |C_j|) * sum_{x in C_j} x；
  24:  end for
  25: until 均值向量不再更新
  输出：簇划分结果 {C_1, C_2, ..., C_k}
  ```
- **算例分析**：以西瓜数据集 4.0 (30个样本) 为例，在限定必连集 $\mathcal{M}$ 和勿连集 $\mathcal{C}$ 条件下，设置 $k=3$，经历 5 轮迭代收敛，给出三个簇的最终划分结果。

### 6.3 约束种子 $k$ 均值算法 (Constrained Seed k-means)
- **核心理念**：利用少量的有标记样本 $S = \bigcup_{j=1}^k S_j$。将这些有标记的样本作为**种子**，初始化 $k$ 个簇的聚类中心。在随后的迭代中，**不改变种子样本的簇隶属关系**（其所属簇被固定死，仅允许未标记样本调整）。
- **算法伪代码**：
  ```
  输入：样本集 D = {x_1, ..., x_m}；少量有标记样本 S = U_{j=1}^k S_j；聚类簇数 k。
  过程：
  1: for j = 1, 2, ..., k do
  2:   基于种子样本计算初始中心：mu_j = (1 / |S_j|) * sum_{x in S_j} x；
  3: end for
  4: repeat
  5:   初始化簇分配为空：C_j = 空集 (1 <= j <= k)；
  6:   for j = 1, 2, ..., k do
  7:     将种子样本固定分入对应的簇：C_j = C_j U S_j；
  8:   end for
  9:   for 各个未标记样本 x_i in D \ S do
  10:    计算 x_i 与各个均值向量 mu_j 的距离 d_ij = ||x_i - mu_j||_2；
  11:    找出距离最近的簇：r = argmin_{j in {1, ..., k}} d_ij；
  12:    将 x_i 划分入对应的簇：C_r = C_r U {x_i}；
  13:  end for
  14:  for j = 1, 2, ..., k do
  15:    更新均值中心：mu_j = (1 / |C_j|) * sum_{x in C_j} x；
  16:  end for
  17: until 均值中心不再更新
  输出：簇划分结果 {C_1, C_2, ..., C_k}
  ```
- **特征**：种子样本不仅初始化了均值位置，还在聚类循环中作为不动点，引导未标记样本围绕它们形成具有实际语义的簇。
